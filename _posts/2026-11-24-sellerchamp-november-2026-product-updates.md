November gave shipping its own home in the platform, rebuilt how catalog categories work, and added variant-level editing inside batches. On top of that, improvements landed across feeds, orders, Walmart, WooCommerce, and Lightspeed. Here is everything that shipped this month.

<h2>Spotlight Feature
</h2>

<h3>Shipments Is Now a First-Class Feature
</h3>

<p>Shipping used to live inside orders. Now it has its own section of the platform.</p>

<h3>What's New:
</h3>

<p><b>Standalone Shipments:</b></p>

<p>A new top-level Shipments link lets you create and manage shipments completely independent of any order. If you need to ship something that came in through a different channel, send a replacement, or fulfill anything that does not have a formal order in SellerChamp, you can now do it directly:</p>

<ul>
<li>Go to the top nav → Shipments → Create Shipment</li>
<li>Enter ship-to details and buy a label. No order required</li>
<li>Manage all shipments, order-tied and standalone, from one place</li>
</ul>

<p><img src="https://cdn.mcauto-images-production.sendgrid.net/45174282d0a602d8/24c35a57-b731-480e-9f6a-7918ab2202b9/2514x1454.png" alt="" loading="lazy"></p>

<p><b>Shipment Insurance:</b></p>

<p>When buying a label, from either Shipments or Orders, you can now insure the shipment at the same step. Find it in the label window under Insurance.</p>

<p><img src="https://cdn.mcauto-images-production.sendgrid.net/45174282d0a602d8/49bc4db7-dfde-4e32-8d0d-f5cf5958875e/2458x1280.png" alt="" loading="lazy"></p>

<h3>Why It Matters:
</h3>

<p>Not every shipment starts with a marketplace order. Replacements, warranty sends, B2B shipments, and internal transfers all need labels too. A standalone Shipments section means you no longer need to create dummy orders or use a separate tool just to generate a label.</p>

<h2>Catalog Updates
</h2>

<h3>Upload Catalog Categories by CSV
</h3>

<p>You can now manage catalog categories in bulk using a CSV upload.</p>

<h3>What's New:
</h3>

<ul>
<li>Download the category template from Settings → Account Setup → Mappings → Categories</li>
<li>Fill in category names and marketplace mappings, then upload</li>
<li>Re-uploading the same category name updates its existing mappings</li>
<li>Failed rows come back as an error report so nothing is silently dropped</li>
</ul>

<p><img src="https://cdn.mcauto-images-production.sendgrid.net/45174282d0a602d8/fb733014-eb21-4a55-93e9-50fb2c4a31fd/2274x1338.png" alt="" loading="lazy"></p>

<h3>Why It Matters:
</h3>

<p>Manually setting up category mappings one at a time is impractical for large catalogs. CSV uploads let you configure and update categories in bulk, and the error report ensures you can find and fix any issues without starting over.</p>

<h3>Limit Which Marketplace Categories Are Shown
</h3>

<p>Per selling channel, you can now control which marketplace categories appear across mapping, product forms, and copy flows.</p>

<h3>What's New:
</h3>

<ul>
<li>Set the category filter at Settings → Account Setup → Mappings → Marketplace Categories</li>
<li>Choose to show all categories, only categories already on your products, or categories from an uploaded file</li>
<li>The setting applies to mapping, product forms, and copy flows for that channel</li>
</ul>

<p><img src="https://cdn.mcauto-images-production.sendgrid.net/45174282d0a602d8/4c2e6bd0-0629-44f8-8e89-507012e32a57/1922x1030.png" alt="" loading="lazy"></p>

<h3>Why It Matters:
</h3>

<p>Marketplaces can have hundreds or thousands of categories. Limiting the visible set to only the categories you actually use makes mapping faster, reduces errors, and keeps dropdowns clean for your team.</p>

<h2>Listings Updates
</h2>

<h3>Add and Manage Variants Individually in a Batch
</h3>

<p>When searching inventory for a batch, variants now appear with their own badge and can be managed independently.</p>

<h3>What's New:
</h3>

<ul>
<li>Variants show with a Variant badge and their option values when you search inventory in a batch</li>
<li>Select a single variant into the batch without pulling in the entire parent product</li>
<li>Use Edit Variant inside the batch to manage that variant on its own</li>
</ul>

<p><img src="https://cdn.mcauto-images-production.sendgrid.net/45174282d0a602d8/a7bfb6ba-6779-48e8-a1c0-9a9c4047866d/1558x936.png" alt="" loading="lazy"></p>

<h3>Why It Matters:
</h3>

<p>Previously, working with a specific variant in a batch required handling the entire parent product. Individual variant selection and editing lets you make targeted changes without affecting unrelated variants or pulling in products you do not need.</p>

<h2>Labels Updates
</h2>

<h3>Discount Price on Price Labels
</h3>

<p>Price labels can now show a discount price alongside the regular price.</p>

<h3>What's New:
</h3>

<ul>
<li>Go to Settings → Account Setup → Labels → Price Labels → Show Discount Price</li>
<li>The discount price is calculated as a percentage of MSRP or the current Amazon price, whichever is lower</li>
<li>Set the percentage and the label displays the discount price automatically</li>
</ul>

<p><img src="https://cdn.mcauto-images-production.sendgrid.net/45174282d0a602d8/f0d5fc9f-86e6-4ca5-b78f-fbc2ac6ca12f/2426x1516.png" alt="" loading="lazy"></p>

<h3>Why It Matters:
</h3>

<p>Showing a discount price on a price label gives customers an immediate reference point for the savings. For sellers who reprice frequently or sell across liquidation and retail channels, this adds useful context directly on the label.</p>

<h2>Improvements and Enhancements
</h2>

<h3>Catalog and Navigation Enhancements
</h3>

<ul>
<li><b>Catalog in the Main Nav</b>: When catalog sync is enabled for your account, Catalog now appears directly in the top navigation so you can get to it in one click</li>
</ul>
